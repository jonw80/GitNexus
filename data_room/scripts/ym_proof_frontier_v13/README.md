# Direct Wilson V13 calculations

Run `python run_v13.py` with Python3.12 and NumPy2.1.3.
This executes exact spatial Haar and temporal projector contractions,
Perron-normalized 2D moment intervals at an explicitly small anisotropic
coupling, adaptive all-volume representation-error bounds and an independent
scalar review. All subprocess exits and nine required outputs are checked.

This does not compute the full isotropic target matrices or prove a
uniform physical spectral gap or continuum Yang–Mills theory.
No private repository audit or full user manuscript is included.
